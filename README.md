# 信用主体分析速写

根据首次评级报告、跟踪评级报告、募集说明书等资料，为指定企业生成可直接用于中文信用研究报告的三段式主体分析。

## 输出内容

1. **股权背景**：成立时间、资本、控股股东、持股比例及实际控制人。
2. **业务经营**：主营业务、经营定位、收入结构和适用的经营指标。
3. **财务状况**：资产负债、资金占用、盈利、债务结构、现金流和已披露授信。

默认在对话中输出三段正文，另附必要的来源、口径或差异说明；指定时可生成 Word 或纯文本文件。

## 安装

在 Codex 中调用 skill-installer，并提供本仓库的技能目录：

```text
$skill-installer https://github.com/Chenoa047/credit-subject-brief/tree/main/skills/credit-subject-brief
```

也可以下载仓库 ZIP，将完整的 `skills/credit-subject-brief` 文件夹复制到本机 Codex 用户技能目录。

## 使用

上传相关资料并指定企业，例如：

```text
$credit-subject-brief 根据附件，为【公司全称】撰写三段式信用主体分析，仔细核对数据。
```

支持仅撰写财务段、更新已有分析、按参考报告调整写法，以及分别分析多个指定主体。若资料涉及多个企业而未指定分析对象，技能会先确认目标企业。

## 数据核验

- 区分目标公司、母公司、子公司及近似名称企业。
- 核对年份、单位、合并或单体口径、审计状态和原始科目。
- 区分营业收入与含税收款、负债与债务、货币资金与现金类资产、受托规模与公司自身资产。
- 在依据附件写作时，优先使用资料中已经披露的最新数据，并明确时点；用户明确要求时再补查更新的官方披露。
- 对未披露数据不补造，对无法解释的来源差异作说明。

本仓库提供写作与核验方法，不包含项目原始报告、用户财务资料或投资入库结论。
