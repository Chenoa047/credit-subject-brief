# 数据核对清单

## 字段来源底稿

建议按下表或等价结构记录需要进入正文的字段，不必为没有使用的数据建立冗长台账。

| 字段 | 主体/口径 | 时点或期间 | 原始单位及值 | 来源文件、页码、表格 | 展示值/处理 |
| --- | --- | --- | --- | --- | --- |
| 例如资产总额 | 目标企业、合并 | 实际报表期末 | 按原表记录 | PDF页与正文页分别记录 | 换算与舍入依据 |

## 数值和期间

- 万元换亿元除以10,000；千元换亿元除以100,000；元换亿元除以100,000,000。业务规模的万户、万吨、万立方米、万平方米等不随金额单位一起转换。
- 保留原始精度用于计算，展示精度与来源和参考报告协调。由分项加总或比例计算得到的数值，与原表尾差区分，不悄悄修改原表合计。
- 年末余额、年度流量、中期流量以及“截至报告出具日”分别对应各自期间。报告发布于2026年，并不意味着财务报表为2026年数据。
- 计算同比需要相同期间及可比口径。以年末比较中期末时写“较上年末”，不得写“同比”；中期与上年全年可以分别列示，不作为同比增减。
- 同一主体的股权、经营、财务、授信和征信可能采用不同截至日，在相应句子中标出。只定性预披露“年度无重大变化”不是该年度具体财务数值。

## 科目和范围

| 易混项 | 核验要求 |
| --- | --- |
| 母公司、集团、子公司 | 对照章节标题、表名、报表编制单位、全称和统一社会信用代码（如有）；同一报告“公司”可能在新章节重新指代另一企业。 |
| 合并、单体、本部 | 不跨口径拼接总资产、负债、收入、利润及现金流。报告列“归母所有者权益”时，不擅自标为所有者权益合计。 |
| 总负债、总债务 | 总负债含经营性负债、准备金、递延收益等，不能等同有息债务。评级调整、应付票据、租赁负债、永续债、表外证券化等按来源定义核对。 |
| 永续债 | 核实计入权益还是负债、评级统计是否调整；不直接把未调整口径称为真实全部杠杆。 |
| 货币资金、现金类资产、现金等价物 | 不互换；受限资金及现金类资产定义按来源。短债覆盖优先引用报告指标，缺失时仅在分子分母可核实后计算。 |
| 应收账款及组合科目 | “应收票据及应收账款”不缩写成应收账款；“其他应收款（合计）”等组合项保留必要限定。 |
| 收入和收款 | 含税供水收入、收费现金、归集现金、营业收入、手续费及佣金收入、手续费及佣金净收入分别处理。金额不同不一定仅由增值税造成，没有调节表时不自行解释。 |
| 利润 | 净利润、归母净利润、营业利润、利润总额和综合收益不可互代。净资产收益率与净利率也不是同一指标。 |
| 现金流 | 经营、投资、筹资净额的正负方向与净流入/流出措辞一致。合计为正不意味着经营获现好；归集到专项计划的现金不等于公司经营现金流量净额。 |
| 授信 | 区分授信总额、已使用、未使用；不把总额说成剩余额度。不把股东/担保人的授信给目标公司，也不重复加总已包含的财务公司额度。授信使用额不等于银行借款余额。 |
| 信托、基金、租赁、担保 | 受托/管理规模不等于公司资产；担保余额不等于负债；监管净资本、监管净资产和合并净资产分别列示。偿付准备金与货币资金不能混用。 |
| 资质和经营权 | 区分取水、生产、供水销售、运营主体及持证名称，不能仅根据同属集团把许可证或产能归属给目标企业。 |
| 评级及信用记录 | 区分主体评级、影子评级和债项评级。征信记录的主体与查询日期必须准确，若原文主语疑似模板残留，不直接引用其“无不良”结论。 |

## 差异处理

1. 检查是否为不同期间、合并范围、税口径、审计/未经审计、追溯调整、债务统计或舍入差异。
2. 原始表与摘要冲突时，记录两个值和位置，优先选能明确主体、期间和口径的原始表；这只是采用理由，不等于已经证实另一值错误。
3. 对非必要指标，省去争议值并使用其他可靠数据。例如综合毛利率在同一报告两处相差0.01个百分点，可只列可核实的分业务毛利率，并在交付说明中指出差异。
4. 对核心指标仍无法确定时，保留可确认的正文，标明该项待核及影响。不要平均两个值、猜测笔误、套用母公司数据或请求用户确认一个尚未查清的数字来替代核验。

## 发表前最后检查

逐句检查“主体—科目—期间—口径—单位—数值—来源”是否闭合，覆盖所有正文数字和实质判断。来源路径或链接必须可用，PDF实际页码和印刷正文页码不要混称。
